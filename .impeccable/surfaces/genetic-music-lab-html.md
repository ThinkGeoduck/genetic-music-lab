# Surface brief: genetic-music-lab.html

## Scope and mode

The whole lab page (start screen and running lab). Mode: Experience — the evolving music leads, the interface recedes. Projected to a room in a talk; must read from the back row.

## Audience, job, constraints

A live audience watching a presenter run a genetic algorithm against a hidden piano piece. Job: hear and see randomness become the piece, generation by generation. Constraints: every current function and control stays (load/example, first minute/2 min, start/pause/reset, normal/fast, play original, reveal, population and mutation sliders, click-to-enlarge graph, live piano). Avoid: SaaS-dashboard cards and stat tiles, dark-and-neon, playful/gimmicky, moody black rooms. Factual copy stays; nothing invented.

## Direction contract

Seed: 3cd71c4b (mode experience, kind pick)

THESIS: A concert poster that is being typeset in front of you — the programme for a piece the algorithm has not yet found.

WORLD: Zürich Tonhalle poster grammar. White ground, one flat saturated colour, black grotesk type at poster scale on a rigid modular grid. Geometry carries musical structure: notes are flat bars, fitness is a ranked bar field. No gradients, shadows, glows, cards, or icons; rules and whitespace do the dividing.

FIRST VIEWPORT: The full-bleed poster. Title small and tracked at the top like a programme heading, the generation number enormous, the two rolls (hidden target / evolving candidate) as the poster's geometric composition, the controls set as a single typographic line at the foot.

VISITOR PATH: Drop file → poster fills with the piece's geometry → press Start → the number counts, the geometry orders itself, the piano plays → Reveal shows the programme's true first line.

SIGNATURE INTERACTION: Correct notes print in black as they land, like type being set; wrong ones stay in the accent colour; the playhead is a hairline crossing the poster. On convergence the poster is finished: nothing pops, the colour field settles.

HONEST RISK: Swiss-poster is familiar; the discipline must be exact (grid, scale jumps, one colour) or it reads as generic.

## Unresolved

Accent colour chosen at build against the piano-roll contrast requirement.
